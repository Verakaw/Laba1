# Портфолио-резюме Веры Соловьёвой

Одностраничный сайт-портфолио для учебного задания по веб-дизайну. Проект собран на стандартном стеке HTML, CSS и JavaScript и подходит для публикации через GitHub Pages.

## Что внутри

- адаптивная вёрстка по принципу Mobile First;
- светлая и тёмная темы с сохранением выбора в `localStorage`;
- интерактивная карусель с 5 материалами проекта «Изба»;
- свайп карусели на мобильных устройствах;
- контакты через email и Telegram;
- контент и визуальные материалы Веры Соловьёвой;
- личное фото Веры в первом экране.

## AI-помощник

В работе использован ChatGPT: он помог спланировать структуру портфолио, предложить информационную архитектуру и провести первичное ревью интерфейса. После проверки я самостоятельно выбрала спокойную бежево-коричневую палитру, переписала тексты под Веру, отобрала слайды ресторана, настроила контакты и проверила мобильную карусель.

## Публикация на GitHub Pages

1. Создать репозиторий и загрузить содержимое этой папки.
2. Открыть `Settings → Pages`.
3. В качестве источника выбрать ветку `main` и папку `/root`.
4. Сохранить настройки и открыть выданную ссылку.

Сайт не требует сборщика или установки зависимостей.
